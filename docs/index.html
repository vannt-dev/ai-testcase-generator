How it works

One shared core engine, per-project config — no code changes needed to add a new project.

1

Pick a project

Each project is a single YAML file: domain rules, glossary, platform, and its own test ID format.

2

Paste a requirement

A user story, Jira ticket, or plain business description — no special formatting required.

3

Claude generates test cases

Structured Output guarantees the schema; the AI asks for clarification if the requirement is incomplete.

4

Edit & export to Excel

Edit directly in the table, add/remove rows, then download a pre-styled .xlsx file.

Features

Built for real use in a QA workflow, not just a demo.

🧩

Per-project config

Domain rules, glossary, platform, test ID format — decoupled from the core engine, no code changes needed.

🔁

Auto-retry on transient errors

Automatically retries with backoff on rate limits or connection loss to the Anthropic API.

💰

Cost tracking

Shows token usage, prompt caching, and an estimated USD cost for every generation run.

🕘

Session history

Keeps recent generation runs from the current session, viewable or restorable anytime.

📊

Pre-styled Excel export

An .xlsx file with priority color-coding, a frozen header, and a Summary sheet — usable right away.

✅

Structured Output

Validated by Pydantic against a fixed schema — no worrying about malformed JSON from the AI.

Setup & try it out

Requires Python ≥ 3.10. See the full details in the README.

git clone https://github.com/vannt-dev/ai-testcase-generator.git
cd ai-testcase-generator
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env          # fill in ANTHROPIC_API_KEY

streamlit run app.py
